第 15 章 · Part 5：Adapters

Built-in Adapters 生態系

OpenCLI 內建超過 80 個平台適配器，讓每一道 CLI 指令都能直接操作各大平台，從社群媒體到開發者工具一應俱全。

Adapter 生態系概覽

Adapter（適配器）是 OpenCLI 的核心概念。每一個 adapter 封裝了特定平台的操作邏輯——認證方式、頁面結構、API 端點——讓你只需要記憶一套統一的 CLI 介面，就能駕馭數十個不同的平台。

OpenCLI 開箱即用的 80+ 內建 adapter 橫跨七大分類，覆蓋了日常工作中最常接觸的平台。無論是抓取 Twitter 趨勢、監控 GitHub Issue、分析 YouTube 頻道，還是搜尋知乎問答，都只需要一行指令。

查看可用 Adapters

在開始使用任何 adapter 之前，可以透過以下指令探索目前可用的 adapter 清單。

列出與篩選

列出所有 adapter 
# 列出所有內建適配器
opencli adapters list

# 依分類篩選
opencli adapters list --category social
opencli adapters list --category video
opencli adapters list --category devtools
opencli adapters list --category ecommerce
opencli adapters list --category knowledge
opencli adapters list --category productivity
opencli adapters list --category news

# 輸出 JSON 格式（方便程式解析）
opencli adapters list --format json

查看詳細資訊

adapters info 會顯示 adapter 的完整說明，包含所有子指令、參數說明和認證需求：

查看 adapter 詳情 
# 查看單一 adapter 詳細資訊
opencli adapters info twitter
opencli adapters info github
opencli adapters info youtube

# 輸出包含所有可用指令
opencli adapters info twitter --commands

# 查看認證策略說明
opencli adapters info linkedin --auth

搜尋 Adapter

搜尋 adapter 
# 關鍵字搜尋 adapter
opencli adapters search video
opencli adapters search "social media"
opencli adapters search taiwan

# 搜尋並顯示詳細資訊
opencli adapters search git --verbose
💡
快速發現指令

執行 opencli adapters info <name> --commands 可以看到該平台所有支援的子指令清單，是探索新 adapter 最快的方式。

適配器分類詳解

社群媒體

社群媒體類 adapter 涵蓋全球主流平台。大多數讀取操作不需要登入；互動功能（按讚、轉發、留言）需要透過 cookie 策略共用瀏覽器登入狀態。

社群媒體 adapter 指令示範 
# Twitter/X：搜尋推文、取得趨勢
opencli twitter search "OpenCLI" --limit 20
opencli twitter trends --location tw

# Facebook：公開粉絲頁貼文
opencli facebook page posts "anthropic" --limit 10

# Instagram：公開帳號貼文
opencli instagram user posts "anthropicai" --limit 12

# LinkedIn：職缺搜尋、人才搜尋
opencli linkedin jobs search "AI Engineer" --location Taiwan
opencli linkedin people search "Porter Yen"

# Mastodon：公開時間軸
opencli mastodon timeline public --limit 30
opencli mastodon search "OpenCLI" --instance mastodon.social

影音平台

影音類 adapter 支援影片搜尋、頻道分析、評論擷取等功能。YouTube 和 Bilibili 是功能最完整的兩個 adapter，支援完整的互動操作。

影音平台 adapter 指令示範 
# YouTube：搜尋影片、頻道資訊
opencli youtube search "TypeScript tutorial" --limit 10
opencli youtube channel info "@Fireship"

# Bilibili：搜尋、排行榜
opencli bilibili search "Python 教學" --limit 20
opencli bilibili ranking --category technology

# Twitch：直播列表、頻道資訊
opencli twitch streams --game "Software and Game Development" --limit 20
opencli twitch channel info "theprimeagen"

# TikTok：搜尋公開影片
opencli tiktok search "coding tutorial" --limit 15

# Vimeo：搜尋高品質影片
opencli vimeo search "motion design" --limit 10 --sort likes

開發者工具

開發者工具類 adapter 是工程師日常自動化的利器。GitHub adapter 尤其強大，支援 Repo 探索、Issue 管理、PR 追蹤等完整工作流。

開發者工具 adapter 指令示範 
# GitHub：熱門 Repo、Issue 管理
opencli github trending --language typescript
opencli github repo issues microsoft/vscode --state open --limit 20

# GitLab：群組專案、MR 管理
opencli gitlab group projects "gitlab-org" --limit 20
opencli gitlab repo mrs "gitlab-org/gitlab" --state opened

# npm：套件搜尋、版本查詢
opencli npm search "browser automation" --limit 10
opencli npm info playwright --versions

# PyPI：Python 套件探索
opencli pypi search "web scraping" --limit 10
opencli pypi info selenium

# Docker Hub：映像檔搜尋
opencli dockerhub search "node" --stars 1000 --limit 20
opencli dockerhub image info "node" --tag 20-alpine

知識平台

知識平台類 adapter 讓你能快速聚合多個來源的知識內容，非常適合用於資料收集和研究工作流。

知識平台 adapter 指令示範 
# 知乎：問題搜尋、熱榜
opencli zhihu search "Claude Code 使用技巧" --limit 20
opencli zhihu hot-list --category technology

# Medium：文章搜尋
opencli medium search "AI Agent development" --limit 10
opencli medium tag "typescript" --limit 20

# Reddit：Subreddit 瀏覽
opencli reddit feed r/MachineLearning --sort hot --limit 30
opencli reddit search "Claude API" --limit 20

# Stack Overflow：問題搜尋
opencli stackoverflow search "how to use playwright" --limit 10
opencli stackoverflow questions --tag typescript --sort votes

# Hacker News：頭條、評論
opencli hackernews top --limit 30
opencli hackernews search "AI automation" --limit 20

電商

電商類 adapter 目前只提供公開商品資訊的讀取功能，包含商品搜尋、價格查詢、評論讀取，不支援結帳或帳號操作。

電商 adapter 指令示範 
# Amazon：公開商品資訊（只讀）
opencli amazon search "mechanical keyboard" --limit 10
opencli amazon product info "B09FXHGTHM"

# Shopify（公開商店）：商品瀏覽
opencli shopify store products "your-store.myshopify.com" --limit 20

# eBay：競標商品搜尋
opencli ebay search "vintage camera" --condition used --limit 15
opencli ebay item info "123456789"
⚠️
電商資料使用注意事項

電商 adapter 僅供個人學習與研究使用，請遵守各平台的服務條款。禁止用於大規模爬取、價格操控或商業競情蒐集。

生產力工具

生產力工具類 adapter 通常需要 API Key 或 Token，需要事先完成設定。這類 adapter 的優勢在於可以將工作管理工具整合進自動化腳本。

生產力工具 adapter 指令示範 
# Notion（需 API Key）：頁面讀取
opencli notion pages list --workspace my-workspace
opencli notion page get <page-id>

# Trello（需 API Key）：看板管理
opencli trello boards list
opencli trello board cards <board-id> --list "In Progress"

# Slack（需 API Token）：頻道訊息
opencli slack channels list
opencli slack channel messages general --limit 20

# Jira（需 API Key）：Issue 追蹤
opencli jira issues list --project MYPROJECT --status "In Progress"
opencli jira issue get MYPROJECT-123

新聞資訊

新聞資訊類 adapter 支援 RSS 聚合和各大科技媒體。RSS adapter 特別靈活，可以訂閱任意標準 RSS/Atom feed。

新聞資訊 adapter 指令示範 
# RSS 聚合器：任意 RSS 來源
opencli rss fetch "https://feeds.feedburner.com/oreilly/radar"
opencli rss fetch "https://techcrunch.com/feed/" --limit 10

# Hacker News：多種版面
opencli hackernews top --limit 30
opencli hackernews ask --limit 20
opencli hackernews show --limit 20

# Product Hunt：今日精選產品
opencli producthunt today --limit 20
opencli producthunt search "AI tools" --limit 15

認證機制總覽

OpenCLI 設計了七種標準化的認證策略，對應不同平台的接入方式。 了解這些策略有助於你判斷操作前是否需要先完成登入，以及遇到認證問題時如何排查。

策略 說明 代表平台 前置需求
public 無需任何憑證，直接讀取公開內容 Hacker News、RSS、PyPI、Docker Hub 無
cookie 共用瀏覽器現有登入 Cookie Twitter/X、YouTube、LinkedIn、知乎 瀏覽器已登入目標平台
api-key 透過 API Token / Secret Key 認證 Notion、Slack、Trello、Jira 平台申請 API Key 並設定 opencli config
oauth 標準 OAuth 2.0 授權流程 GitHub（寫入操作）、GitLab 執行 opencli auth login <platform>
local 無頭瀏覽器直接操作，無帳號概念 內部系統、Intranet、本地服務 確保目標 URL 可達
intercept 攔截瀏覽器 XHR/Fetch 取得 API 回應 Bilibili（部分）、TikTok 瀏覽器已登入目標平台
ui 模擬 UI 互動完成登入或操作 Instagram、Facebook（互動功能） 瀏覽器已登入目標平台
ℹ️
多策略 adapter

部分 adapter 會依操作類型切換策略。例如 GitHub 的讀取操作使用 public，而建立 Issue 或 Star Repo 等寫入操作則切換到 oauth，OpenCLI 會自動處理這個切換邏輯。

Adapter 版本管理

平台會不斷更新介面和 API，OpenCLI 提供完整的 adapter 版本管理機制，讓你能隨時更新、也能在出現問題時快速回滾。

Adapter 版本管理指令 
# 查看所有 adapter 版本
opencli adapters version

# 查看特定 adapter 版本
opencli adapters version twitter
opencli adapters version --category social

# 更新全部 adapter
opencli adapters update

# 更新特定 adapter
opencli adapters update twitter
opencli adapters update github youtube

# 回滾到前一個版本
opencli adapters rollback twitter

# 回滾到指定版本
opencli adapters rollback twitter --to 2.1.0

# 查看可用版本歷史
opencli adapters version twitter --history

版本相依關係

每個 adapter 都有對應的 OpenCLI 主程式版本需求。執行 opencli adapters update 時，系統會自動檢查相容性，避免安裝不相容的版本。

狀況 說明 建議動作
adapter 版本過舊 平台改版導致部分功能失效 opencli adapters update <name>
更新後功能異常 新版 adapter 可能有 breaking change opencli adapters rollback <name>
OpenCLI 主程式太舊 新版 adapter 需要更新的核心功能 先更新 OpenCLI 主程式
版本被鎖定 專案需要固定版本確保穩定 使用 opencli adapters version --pin
💡
CI 環境建議

在 CI/CD 環境中，建議使用 opencli adapters version --pin 將 adapter 版本鎖定，並將鎖定檔案提交至版本控制，確保每次執行的行為一致。

社群 Adapter 生態

除了官方內建的 80+ adapter，OpenCLI 社群也貢獻了大量第三方 adapter，覆蓋更多小眾平台和垂直場景。 這些社群 adapter 以 npm 套件形式發布，命名規範為 opencli-adapter-<name>。

安裝社群 Adapter

社群 adapter 安裝與管理 
# 從 npm 安裝社群 adapter
opencli adapters install opencli-adapter-lobsters
opencli adapters install opencli-adapter-devto
opencli adapters install opencli-adapter-producthunt

# 安裝並指定版本
opencli adapters install opencli-adapter-lobsters@1.2.0

# 從本地目錄載入（開發中的 adapter）
opencli plugin load ./my-custom-adapter/adapter.yaml

# 列出已安裝的社群 adapter
opencli adapters list --source community

# 解除安裝社群 adapter
opencli adapters uninstall opencli-adapter-lobsters

搜尋社群 adapter 
# 在 npm registry 搜尋社群 adapter
npm search opencli-adapter

# 在 GitHub 搜尋（使用 GitHub adapter 本身！）

# 查看熱門社群 adapter

貢獻 Adapter

想為 OpenCLI 社群貢獻一個新的 adapter？基本流程如下：

Step 1：開發

參考第 17 章，用 YAML 或 TypeScript 撰寫 adapter，本地測試確認功能正常。

Step 2：打包

建立 npm 套件，加入 "opencli" 和 "opencli-adapter" keywords，方便被搜尋發現。

Step 3：發布

執行 npm publish 發布到 npm registry，並在 GitHub 加入 opencli topic。

Step 4：提交收錄

向 OpenCLI 官方 repo 提交 PR，申請加入 marketplace 精選清單，增加曝光度。

適配器健康狀態

平台本身可能發生故障、改版或封鎖，OpenCLI 提供健康狀態監控機制，讓你能快速掌握每個 adapter 目前是否正常運作。

Adapter 健康檢查指令 
# 批次健康檢查（所有 adapter）
opencli adapters health

# 單一 adapter 狀態
opencli adapters health twitter
opencli adapters health github

# 指定分類健康檢查
opencli adapters health --category social

# 輸出 JSON 格式
opencli adapters health --format json

健康狀態碼說明

狀態碼 含義 常見原因 建議動作
ok 正常運作 — 無需處理
degraded 效能降低或部分功能異常 平台局部改版、速率限制、網路延遲 更新 adapter 或稍後重試
offline 完全無法連線 平台維護、DNS 問題、防火牆封鎖 確認網路；等待平台恢復
auth-required 需要認證才能繼續 Cookie 過期、API Key 無效、Token 失效 重新登入或更新 API Key

自動化健康檢查腳本

將健康檢查加入定期排程，在 adapter 出問題時及時收到通知：

health-check.sh — 定期健康監控腳本 
#!/bin/bash
# 每日健康檢查腳本：health-check.sh

REPORT=$(opencli adapters health --format json)
DEGRADED=$(echo "$REPORT" | jq '[.[] | select(.status == "degraded")] | length')
OFFLINE=$(echo "$REPORT" | jq '[.[] | select(.status == "offline")] | length')

if [ "$OFFLINE" -gt 0 ]; then
  echo "警告：$OFFLINE 個 adapter 離線"
  echo "$REPORT" | jq '.[] | select(.status == "offline") | .name'
fi

if [ "$DEGRADED" -gt 0 ]; then
  echo "注意：$DEGRADED 個 adapter 效能降低"
fi
ℹ️
搭配 OpenCLI Cron 使用

你也可以使用 opencli cron add "0 9 * * *" "opencli adapters health --format json" 將健康檢查排進每日定時任務，不需要額外維護 shell 腳本。

本章小結

OpenCLI 的 adapter 生態系是整個工具最有價值的部分之一。80+ 內建 adapter 加上持續成長的社群貢獻，讓你幾乎可以用同一套 CLI 介面操作所有主要平台。

掌握以下三件事，就能充分運用 adapter 生態：

  • 用 opencli adapters list 和 adapters info 探索可用能力
  • 了解七種認證策略，判斷操作前需要什麼前置條件
  • 定期執行 opencli adapters health，掌握 adapter 健康狀態
