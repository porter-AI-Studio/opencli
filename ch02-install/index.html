第 2 章 · Part 1：入門

安裝與環境設定

從零到可用，10 分鐘完成 OpenCLI 全套環境設定。

系統需求

項目 最低需求 建議版本
Node.js 18.0.0 20.x LTS 或 22.x
npm 9.0.0 10.x（隨 Node.js 20 附帶）
Chrome 110+ 最新穩定版
作業系統 — macOS / Linux / Windows 10+
記憶體 4GB RAM 8GB RAM（同時操作多個 Tab）
⚠️
Node.js 版本要求

OpenCLI 使用 ES Modules 語法，需要 Node.js 18 以上版本。如果你的系統安裝的是舊版本，請使用 nvm 進行升級。

Step 1：確認 Node.js 版本

確認版本 
node --version
# 應輸出 v18.x.x 或更高

npm --version
# 應輸出 9.x.x 或更高

如果版本不符，使用 nvm 安裝正確版本：

使用 nvm 管理版本（macOS / Linux） 
# 安裝 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# 安裝 Node.js 20 LTS
nvm install 20
nvm use 20
nvm alias default 20
使用 nvm-windows（Windows） 
# 下載並安裝 nvm-windows
# 安裝後在 PowerShell 執行：
nvm install 20.0.0
nvm use 20.0.0

Step 2：安裝 OpenCLI

全域安裝 
npm install -g opencli

安裝完成後確認：

確認安裝 
opencli --version
# 輸出: opencli v2.x.x

opencli --help
# 顯示所有可用指令

Step 3：安裝 Browser Bridge Extension

Browser Bridge Extension 是 OpenCLI 的核心組件之一，負責在 Chrome 和 OpenCLI daemon 之間建立通訊橋梁。

方法 A：從 Chrome Web Store 安裝（推薦）

  1. 開啟 Chrome 瀏覽器
  2. 前往 Chrome Web Store 搜尋「OpenCLI Browser Bridge」
  3. 點擊「加到 Chrome」
  4. 確認安裝後，工具列會出現 OpenCLI 圖示

方法 B：手動載入開發版本

下載 Extension 
# 從 GitHub 下載最新版本
git clone https://github.com/opencli/browser-bridge-extension
cd browser-bridge-extension
npm install && npm run build
  1. 開啟 chrome://extensions/
  2. 啟用右上角「開發人員模式」
  3. 點擊「載入未封裝項目」
  4. 選擇 browser-bridge-extension/dist 資料夾

Step 4：啟動 Daemon

OpenCLI 需要一個後台常駐服務（daemon）來管理瀏覽器連線：

啟動 daemon 
# 啟動 daemon（預設端口 7070）
opencli daemon start

# 確認 daemon 正在運行
opencli daemon status
# 輸出: daemon is running on port 7070

# 查看 daemon 日誌
opencli daemon logs
💡
讓 daemon 開機自動啟動

在 macOS 上可以用 opencli daemon install 將 daemon 安裝為系統服務，開機後自動啟動，不需要每次手動執行。

Step 5：執行診斷檢查

opencli doctor 
opencli doctor

正常輸出應如下：

doctor 輸出範例 
✅ Node.js v20.11.0 (required: >=18)
✅ OpenCLI v2.3.1
✅ Daemon is running on port 7070
✅ Browser Bridge Extension detected (Chrome)
✅ Connected to 2 browser tab(s)
✅ All systems operational

常見安裝問題

EACCES：Permission denied（macOS / Linux）

全域安裝 npm 套件時遇到權限問題：

修復 npm 權限問題 
# 方法一：使用 nvm（推薦）
# nvm 安裝的 Node.js 不需要 sudo

# 方法二：修改 npm 全域目錄
mkdir -p ${HOME}/.npm-global
npm config set prefix '${HOME}/.npm-global'
echo 'export PATH=${HOME}/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

SSL/TLS 憑證錯誤（企業網路）

企業 proxy 設定 
npm config set proxy http://proxy.company.com:8080
npm config set https-proxy http://proxy.company.com:8080
npm config set cafile /path/to/corporate-ca.crt

PowerShell 執行原則錯誤（Windows）

修改 PowerShell 執行原則 
# 以系統管理員執行 PowerShell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Extension 載入失敗

如果 opencli doctor 顯示 Extension 未連接：

  1. 確認 Extension 已啟用（chrome://extensions/ 中檢查）
  2. 點擊 Extension 圖示，確認「連接狀態」顯示為綠色
  3. 嘗試在 Extension 選項頁面點擊「重新連接」
  4. 重啟 daemon：opencli daemon restart

Port 7070 被佔用

使用其他端口 
opencli daemon start --port 7071
# 或設定環境變數
export OPENCLI_DAEMON_PORT=7071

更新 OpenCLI

更新到最新版本 
npm update -g opencli
opencli --version
ℹ️
版本相容性

OpenCLI CLI、Daemon 和 Browser Bridge Extension 三個組件的主版本號必須相同。升級時請確保三個組件一起更新，避免版本不一致導致的連線問題。

解除安裝

完整解除安裝 
opencli daemon stop
opencli daemon uninstall
npm uninstall -g opencli
🚀
安裝完成！

如果 opencli doctor 顯示所有項目都是 ✅，你已準備好開始第一個自動化任務了。繼續閱讀下一章了解如何上手！
