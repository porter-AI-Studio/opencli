這份指南涵蓋什麼？

不只是基礎操作，更深入 OpenCLI 的強大功能與實戰應用

🔑
零憑證操作
直接複用 Chrome 已登入的 Session，無需 API Key 或帳密，免重做登入流程。
🖱️
瀏覽器自動化
open / find / click / fill / eval / screenshot，完整指令操控任意網頁。
🧪
E2E 測試
搭配 Vitest 快速建立 E2E 測試套件，chatbot / Web 應用皆適用。
🤖
AI Agent 整合
在 Claude Code 中安裝 opencli-browser Skill，用自然語言驅動瀏覽器。
🌐
100+ 平台支援
內建 Twitter/X、YouTube、Bilibili、GitHub 等平台 Adapter，開箱即用。
🔧
Custom Adapter
自製任意網站的 Adapter，讓每個網站都有專屬的 CLI 子命令。
