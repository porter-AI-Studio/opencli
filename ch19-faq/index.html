第 21 章 · Part 6：比較與實戰

常見問題 & FAQ

遇到問題？這裡收錄了最常見的 16 個使用疑難，附上完整解決方案。

連線與環境問題

Q1：daemon 無法啟動，顯示 "Address already in use"

端口 7070 已被其他程序佔用：

解決方案 
# 找出佔用端口的程序
lsof -i :7070         # macOS / Linux
netstat -ano | findstr :7070  # Windows

# 強制停止舊的 daemon
opencli daemon stop --force

# 或使用不同端口
opencli daemon start --port 7071
export OPENCLI_DAEMON_PORT=7071

Q2：Browser Bridge Extension 顯示「未連接」

Extension 和 Daemon 之間的 WebSocket 連線中斷：

排除步驟 
# 1. 確認 daemon 正在運行
opencli daemon status

# 2. 重啟 daemon
opencli daemon restart

# 3. 重新整理 Extension（在 chrome://extensions/ 頁面點擊重新整理圖示）

# 4. 全套診斷
opencli doctor

如果問題持續，檢查防火牆是否阻擋了 localhost:7070 的連線。

Q3：在 CI/CD 環境中執行失敗，顯示 "No browser connected"

CI 環境沒有實體瀏覽器，需要改用 CDP 模式：

CI 環境設定 
# 使用 browserless 容器
docker run -d -p 3000:3000 browserless/chromium

# 設定 CDP 端點
export OPENCLI_CDP_ENDPOINT=ws://localhost:3000

# 執行指令
opencli browser work navigate "https://example.com"

詳細 CI 設定請參考第 11 章。

Q4：連線超時，顯示 "Browser connect timeout"

調整超時設定 
# 增加連線超時時間（預設 10 秒，單位毫秒）
export OPENCLI_BROWSER_CONNECT_TIMEOUT=30000

# 或在指令中指定
opencli --timeout 30000 browser work navigate "https://slow-site.com"

Session 與 Profile 問題

Q5：多個 Session 操作時互相干擾

Session 名稱衝突，兩個任務操作了同一個分頁：

Session 隔離 
# 使用不同的 Session 名稱
opencli browser task-a open "https://site-a.com"
opencli browser task-b open "https://site-b.com"

# 查看所有 Session
opencli browser list

# 確認每個 Session 對應正確的分頁
opencli browser task-a screenshot --output a.png
opencli browser task-b screenshot --output b.png

Q6：Chrome Profile 衝突，Extension 連接到錯誤的 Profile

如果你有多個 Chrome Profile，需要確認 Extension 安裝在正確的 Profile 中：

Profile 管理 
# 查看當前連接的 Profile 資訊
opencli browser info

# 如果需要切換 Profile，在啟動 Chrome 時指定
google-chrome --profile-directory="Profile 1"

# 確認 Extension 在目標 Profile 中已啟用
# chrome://extensions/ → 確認 OpenCLI Browser Bridge 已啟用

元素定位問題

Q7：N-ref 操作後顯示 "Element not found: [N]"

N-ref 是頁面快照，頁面更新後舊的 N-ref 就失效了：

重新取得 N-ref 
# ❌ 錯誤做法：假設 N-ref 永久有效
opencli browser work state  # 取得 [1] = 搜尋框
# ... 一段時間後 ...
opencli browser work type "[1]" "新搜尋"  # 可能失敗！

# ✅ 正確做法：操作前重新執行 state
opencli browser work state
opencli browser work type "[1]" "新搜尋"  # 立即使用

Q8：state 指令找不到目標元素

元素可能在 iframe 中，或是動態載入的：

處理特殊元素 
# 等待動態元素載入後再取得 state
opencli browser work wait --selector ".dynamic-content"
opencli browser work state

# 如果元素在 iframe 中，使用 CSS selector 直接操作
opencli browser work click "iframe#myframe button.submit"

# 使用 evaluate 操作 iframe 內的元素
opencli browser work evaluate "document.getElementById('myframe').contentDocument.querySelector('.btn').click()"

輸入與互動問題

Q9：type 指令輸入後沒有觸發表單驗證

某些框架（React、Vue）的 input 需要觸發特定事件才能更新狀態：

觸發框架事件 
# 方法一：使用 fill（模擬真實使用者輸入，觸發 input/change 事件）
opencli browser work fill "[1]" "my-input-value"

# 方法二：用 evaluate 手動觸發事件
opencli browser work evaluate "const el = document.querySelector('#my-input'); el.value='my-value'; el.dispatchEvent(new Event('input', { bubbles: true })); el.dispatchEvent(new Event('change', { bubbles: true }));"

Q10：click 指令點擊後沒有反應

元素可能被其他元素覆蓋，或需要先捲動到可視範圍：

點擊問題排查 
# 先捲動到元素位置
opencli browser work scroll "[5]"

# 使用 evaluate 直接呼叫 click（繞過覆蓋問題）
opencli browser work evaluate "document.querySelectorAll('.btn')[4].click()"

# 截圖確認頁面狀態
opencli browser work screenshot --output debug.png

Q11：select 下拉選單無法選取正確選項

下拉選單操作 
# 使用 select 指令（比 click 更穩定）
opencli browser work select "[3]" "option-value"

# 如果是自定義下拉選單（非原生 select），用 click 模擬
opencli browser work click "[3]"  # 展開選單
opencli browser work wait --text "選項文字"
opencli browser work click "[N]"  # 點選目標選項

資料擷取問題

Q12：extract 擷取結果為空

Selector 不正確，或頁面尚未完全載入：

debug extract 
# 確認 selector 存在
opencli browser work evaluate "document.querySelectorAll('.target-class').length"

# 等待內容載入後再擷取
opencli browser work wait --selector ".target-class"
opencli browser work extract --selector ".target-class"

# 查看頁面原始碼確認 selector
opencli browser work evaluate "document.querySelector('.target-class')?.outerHTML"

Q13：network 指令攔截不到 API 請求

需要在頁面載入前就開始攔截：

正確的 network 攔截順序 
# ✅ 正確：先設定攔截，再導航
opencli browser work network intercept --pattern "*/api/*"
opencli browser work navigate "https://example.com"

# ❌ 錯誤：先導航再攔截（可能錯過請求）
opencli browser work navigate "https://example.com"
opencli browser work network intercept --pattern "*/api/*"  # 太晚了

版本與相容問題

Q14：升級後 Adapter 指令失效

主版本升級可能有 Breaking Changes：

版本管理 
# 查看當前版本
opencli --version
opencli adapter info twitter

# 查看 changelog
opencli changelog

# 如需回滾
npm install -g opencli@2.2.0

Q15：CLI、Daemon、Extension 版本不一致

版本同步 
# 查看所有組件版本
opencli doctor

# 更新所有組件
npm update -g opencli
# 然後在 chrome://extensions/ 更新 Extension

效能與快取問題

Q16：相同指令第一次慢、後面快，但突然又變慢了

Adapter 快取過期，或瀏覽器 Session 中斷後重建：

快取管理 
# 清除 Adapter 快取
opencli cache clear

# 清除特定平台快取
opencli cache clear --adapter twitter

# 查看快取狀態
opencli cache status

# 強制跳過快取（重新從網路取得）
opencli --no-cache twitter trends
