第 3 章 · Part 1：入門

快速上手：第一個自動化

五個實戰練習，30 分鐘建立 OpenCLI 操作直覺。

💡
前置確認

開始前請確認：opencli doctor 所有項目皆為 ✅，且 Chrome 瀏覽器已開啟。

練習一：你的第一個指令

讓我們從最簡單的開始——查看 Twitter/X 的熱門趨勢：

第一個 OpenCLI 指令 
opencli twitter trends

你應該會看到類似這樣的輸出：

輸出範例 
[
  { "rank": 1, "name": "#AI", "tweetCount": "125K" },
  { "rank": 2, "name": "Claude", "tweetCount": "89K" },
  { "rank": 3, "name": "#TypeScript", "tweetCount": "67K" }
]

這就是 OpenCLI 的魔法：一行指令，結構化的 JSON 輸出，不需要任何程式碼，也不需要帳號密碼。 OpenCLI 直接使用你瀏覽器已登入的 Twitter 帳號獲取資料。

練習二：認識 Session 概念

Session 是 OpenCLI 管理瀏覽器分頁的方式。每個 Session 對應到瀏覽器中的一個分頁， 你可以同時管理多個 Session，讓不同的自動化任務並行運作。

Session 基本操作 
# 開啟一個命名 Session（建立新分頁）
opencli browser work open https://www.google.com

# 查看目前所有 Session
opencli browser list

# 在指定 Session 中操作
opencli browser work navigate "https://news.ycombinator.com"

# 關閉 Session
opencli browser work close
ℹ️
Session 命名慣例

Session 名稱可以是任意字串。建議用能反映任務的名稱，如 twitter、github、research，方便在多工時識別。

練習三：Google 搜尋自動化

讓我們做一個稍微複雜一點的任務——自動化 Google 搜尋並擷取結果：

Google 搜尋自動化 
# 開啟 Google
opencli browser search open https://www.google.com

# 取得頁面狀態（顯示可互動元素）
opencli browser search state

# 在搜尋框輸入關鍵字（[1] 是第一個輸入欄位）
opencli browser search type "[1]" "OpenCLI browser automation"

# 按下 Enter 搜尋
opencli browser search keys Enter

# 等待結果載入
opencli browser search wait --text "搜尋結果"

# 擷取搜尋結果標題
opencli browser search extract --selector "h3" --limit 10

理解 state 指令與 N-ref 系統

state 指令是 OpenCLI 的核心功能之一。它會掃描當前頁面， 為所有可互動元素（按鈕、輸入框、連結等）標上 [N] 編號，稱為 N-ref。

state 指令輸出示意 
[1] <input> id=APjFqb  (搜尋框)
[2] <button>           Google 搜尋
[3] <a> href=/...      OpenCLI GitHub
[4] <a> href=/...      OpenCLI 官方文件

取得 N-ref 之後，你可以用 [N] 語法直接操作元素，不需要記住複雜的 CSS selector。

練習四：YouTube 影片探索

OpenCLI 的 YouTube 適配器讓你能直接查詢影片：

YouTube 影片搜尋 
# 搜尋影片
opencli youtube search "AI coding tutorial" --limit 5

# 取得頻道最新影片
opencli youtube channel videos "@Fireship" --limit 10

# 取得影片詳細資訊
opencli youtube video info "dQw4w9WgXcQ"

# 取得影片評論
opencli youtube video comments "dQw4w9WgXcQ" --limit 20

Bilibili（B 站）也有專屬適配器：

Bilibili 影片操作 
# 搜尋 B 站影片
opencli bilibili search "程式教學" --limit 10

# 取得排行榜
opencli bilibili ranking --category technology

練習五：截圖與資料擷取

截圖操作 
# 截取當前頁面截圖
opencli browser work screenshot --output screenshot.png

# 截取完整頁面（包含捲動區域）
opencli browser work screenshot --full-page --output full-page.png

# 截取特定元素
opencli browser work screenshot --selector ".product-card" --output card.png
資料擷取 
# 擷取頁面所有連結
opencli browser work extract --selector "a" --fields "text,href"

# 擷取表格資料
opencli browser work extract --selector "table tr" --format json

組合使用：每日資訊彙整

每日資訊彙整腳本（daily-brief.sh） 
#!/bin/bash
echo "=== 今日資訊彙整 ==="

echo "--- Twitter 熱門話題 ---"
opencli twitter trends | head -5

echo "--- GitHub 今日熱門 ---"
opencli github trending --language javascript --limit 5

echo "--- Hacker News 頭條 ---"
opencli browser hn open https://news.ycombinator.com
opencli browser hn extract --selector ".storylink" --limit 10

# 截圖備存
opencli browser hn screenshot --output "daily-hn-$(date +%Y%m%d).png"
echo "=== 彙整完成 ==="

常見新手問題

Q：執行指令後沒有反應？

opencli daemon status
opencli doctor

Q：找不到 N-ref 對應的元素？

N-ref 是執行 state 時產生的快照，頁面更新後需要重新執行 state 取得新的 N-ref。

Q：type 指令輸入後沒有效果？

試試改用 fill 指令，它會先清除輸入框再填入內容：

# fill 會清除現有內容後輸入
opencli browser work fill "[1]" "新的內容"

# type 會在現有內容後追加
opencli browser work type "[1]" "追加的內容"

挑戰練習：Reddit 資訊擷取

試著完成以下任務：

  1. 使用 OpenCLI 開啟 Reddit 的 r/programming 頁面
  2. 擷取前 10 篇文章的標題和連結
  3. 對第一篇文章截圖
  4. 將結果輸出成 JSON 格式
查看解答
Reddit 練習解答 
opencli browser reddit open "https://www.reddit.com/r/programming"
opencli browser reddit wait --selector "h3"
opencli browser reddit extract --selector "h3" --fields "text" --limit 10
opencli browser reddit screenshot --selector "[1]" --output first-post.png
opencli reddit feed r/programming --limit 10 --format json
